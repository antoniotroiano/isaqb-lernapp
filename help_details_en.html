Scoring examples (exam mode)

Basic principle: correct ticks earn points proportionally, wrong ticks deduct proportionally, never below 0 per question. Points per question: 1–2 (shown in the question header). Leaving something out deducts nothing, only wrong ticks cost.

A question, 2 points, exactly 1 correct

Answer Points
no selection 0
the correct one ticked 2
one wrong ticked 0
several ticked 0

P question, 2 points, 2 of 4 correct (each correct = 1 point)

Answer Calculation Points
no selection – 0
both correct 1 + 1 2
1 correct + 1 wrong 1 − 1 0
only 1 correct (1 left out) 1 1
both wrong −1 − 1 → min 0 0
more than 2 ticked – 0

P question, 1 point, 4 correct (each correct = 0.25)

Answer Calculation Points
4 correct 4 × 0.25 1
3 correct + 1 wrong 3 × 0.25 − 0.25 0.5
2 correct + 2 wrong 0.5 − 0.5 0
1 correct + 3 wrong 0.25 − 0.75 → min 0 0
2 correct, 2 left out 2 × 0.25 0.5

K question (assignment), 1 point, 3 rows (each correct row = 1/3)

Assignment Calculation Points
all 3 correct 3 × 1/3 1
no assignment – 0
2 correct + 1 wrong 2/3 − 1/3 1/3
1 correct + 2 wrong 1/3 − 2/3 → min 0 0
2 correct, 1 row empty 2 × 1/3 2/3

Rules of thumb

  • Ticking more than required (A: more than 1 · P: more than N) = 0 points for the whole question.
  • A question never goes negative. Mistakes in one question do not deduct points from other questions.
  • Passing: at least 60 % of the sum of all achievable points.
  • In practice mode there are no points: a question only counts if it is completely correct.

Study material

  • "📊 At a glance": many learning goals start with a collapsed block holding a visual overview and a self-test to reveal. Tap to open it.
  • Search: the search field filters live while typing and ignores case. Search by learning goal number (LZ 03-08 or 03-08), keyword (coupling, ATAM) or chapter (Chapter 3). A learning goal number also shows goals that refer to it. Hits open automatically.
  • Jump straight there: in the feedback after a question, tap the LZ number to reach the matching section. The button at the top ("← Back to the question") takes you back to the same spot.

Statistics & backing up data

  • Statistics: exam readiness estimate (R1/R2 hit rate against the 60 % mark), coverage (seen / secure), hit rate by relevance, question type and chapter, weakest chapters with a "practise" button, and the exam history.
  • Export/Import: in the statistics you save your progress as text or a .json file and load it on another device or browser. This is needed because progress is stored only locally in the browser.
  • Revised questions: if an already answered question was changed in content, the app asks whether to reset the statistics of only those questions. Everything else stays.

Handling

  • Keyboard (desktop): in the quiz, 1–9 choose the answer, Enter or space triggers "Check"/"Next", ← goes back, G marks "Guessed / memorized". For K questions, 1 and 2 choose the category of the highlighted row and move on to the next one, ↑ ↓ change the row. In flashcards, Enter reveals, 1 = didn't know, 2 or Enter = knew it. The answer rows can also be reached with Tab.
  • Question overview: shows all question numbers with their status (exam: answered · practice: right/wrong · ★ bookmarked). A click jumps to the question. Before evaluation the app asks if questions are still open.
  • Back: "← Back" in the bottom bar shows earlier questions again. In exam mode answers stay editable and the final selection is scored. The browser back button pauses a running round.
