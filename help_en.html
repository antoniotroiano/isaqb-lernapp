iSAQB CPSA-F Trainer — Guide

Practice app for preparing for the CPSA-F certification (Certified Professional for Software Architecture – Foundation Level). It runs in the browser, without installation and without an account, and contains 312 original questions on all 6 chapters of the curriculum (269 exam-relevant R1/R2, 43 for deeper study only R3) plus the official iSAQB example exam. The interface and all content are available in German and English (toggle DE/EN top right).

Version 1.19.0 · Deutsche Version · Details: scoring examples, search, keyboard

1. Getting started

  • Web link (recommended, works everywhere): https://antoniotroiano.github.io/isaqb-lernapp/
  • Add to home screen: iPhone (Safari) Share → "Add to Home Screen" · Android (Chrome) menu ⋮ → "Add to Home screen".
  • Local (PC/Mac only): download or clone the repository and open index.html with a double click (the css/ and js/ folders must sit next to it). Works fully offline. This does not work on iPhone, use the web link there.
  • Progress is stored locally in the browser and never leaves your device. It applies per device and browser; move it between devices with Export/Import (under 📊 Statistics).

3. The essentials when practising

  • Filters: chapter (1–6), exam relevance (R1/R2/R3) and number of questions per round.
  • Selection: Only wrong answers, Only bookmarks (star on the question), Prefer mistakes, Shuffle answers.
  • 🎲 Guessed / memorized (key G): mark a correctly answered question this way if you guessed or only know the answer by heart. It counts as correct but does not move up a box and comes back sooner. Also possible after checking.
  • Pause / resume: an interrupted round is saved.
  • Review answers: after each round you see the wrong questions with solution and reasoning.
  • Statistics 📊: exam readiness estimate, hit rate by chapter, type and relevance, weakest chapters, export/import.
  • Dark mode 🌓 and language DE/EN top right. When a new app version is out, an update notice appears, your progress is kept.

4. Question types & scoring

Each question states how many answers to choose and how many points it is worth (1–2).

Type Meaning Scoring (exam mode)
A One correct answer Correct = full points, otherwise 0.
P "Pick N" from several Each correct tick +points/N, each wrong tick −points/N, never below 0. More than N ticked = 0.
K Assignment, one of 2 categories per row Each correct row +points/m, each wrong row −points/m, never below 0.

Passing: at least 60 % of the achievable points. Leaving an answer empty costs nothing, only wrong ticks do.

Important: the result in practice mode is a rate (completely correct questions divided by all questions) and has no partial points. Real point scoring only exists in the exam modes. Worked examples are in the Details.

8. Technology & privacy

  • Plain HTML, CSS and JavaScript without external dependencies, questions as data in the code.
  • The app sends no data to any server and uses no trackers. With the web link, the page is loaded once from GitHub Pages.
  • Progress is stored in your browser's localStorage. Clearing browser data or "Reset progress" means starting from zero.
